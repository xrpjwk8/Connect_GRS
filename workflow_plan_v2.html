Master Workflow Architecture v2

단체 예약 매칭 플랫폼 '커넥트' 워크플로우

사용자 피드백, 실시간 동기화 및 오프라인 예약 대처 수동 블락 로직 반영

✨ 업데이트 완료: 점주용 '터치 한 번으로 타임 블락' UI/시스템 설계 추가

1. 유저 정의 및 프로필 포맷 (User Profile Format)

👨‍🍳 1. 점주 회원 (Provider Side)

신뢰 형성 핵심 장치: 실명 기반 소통 및 게이미피케이션 테두리

  • 프로필 사진: 매장 로고, 간판 사진 또는 신뢰감을 주는 점주 셀카
  • 노출 이름 형식: [가게명] 사장 [이름]
    (예: 땅땅치킨 사장 오효준)
  • 신뢰도 시각화: 예약 성공률 및 노쇼 대응 지수에 따라 프로필에 👑 왕관 마크 또는 VIP 테두리 부여
🙋‍♂️ 2. 예약자 회원 (Booker Side)

책임감 부여 장치: 소속 대학 공식 직책 노출

  • 프로필 사진: 학교 마크, 학과 로고 또는 본인 신원 확인 셀카
  • 노출 이름 형식: [학교명] [학과/단체] [직책] [이름]
    (예: 연세대 인공지능학과 회장 윤태웅)
  • 신뢰도 시각화: 노쇼 프리(No-Show Free) 인증 마크 및 거래 횟수별 엠블럼

2. 유저별 디테일 워크플로우 (Detailed Workflow)

🍊 점주(Owner) 이용 흐름
  1. 1. 앱 진입 및 권한 보완

    앱 최초 실행 후 소셜 로그인 진행 (권한 팝업은 최초가 아닌 실제 필요 시점에 띄워 이탈 방지)

  2. 2. 신분 선택 및 가입 정보 입력

    역할을 '점주'로 선택 후 가게명, 연락처, 매장 최대 수용 가능 인원 정보 기입

  3. 3. 사업자등록증 검증 서버 확인

    사업자등록증 사진 업로드 진행 후 대기. 관리자 대시보드에서 확인 후 수동 승인 완료 시 서비스 활성화

  4. 4. 오프라인 예약 대처 (타임 블락) 신규 기능

    전화나 지인을 통해 매장 예약이 찬 경우, 사장님 캘린더 화면에서 해당 타임 블록을 딸깍 한 번 터치하여 [수동 예약 차단] 등록

  5. 5. 예약 요청 알림 수신 실시간 푸시

    예약자가 수동 잠금되지 않은 오픈 타임에 요청서를 보내면 실시간 푸시(FCM) 알림 수신

  6. 6. 요청서 확인 후 수락 (최종 매칭)

    매장 상황 확인 후 '수락' 버튼 터치 시 즉시 예약 확정 및 실시간 타임 차감

🍏 예약자(Booker) 이용 흐름
  1. 1. 앱 진입 및 권한 보완

    앱 최초 실행 및 로그인. 푸시 알림, 카메라 등은 해당 액션이 일어날 때 유동적으로 권한 요청

  2. 2. 신분 선택 및 프로필 생성

    역할을 '예약자'로 선택 후 학교명, 학과명, 직책(회장/부회장 등), 이름 선택 입력

  3. 3. 대학생 신원 인증 서버 확인

    에브리타임 캡처본 업로드 혹은 학교 웹메일(.ac.kr) 인증을 통해 허위 가입 및 노쇼 리스크 차단

  4. 4. 스마트 필터링 검색 UI 피드백

    장소(예: 신촌), 날짜, 시간, 인원수를 설정하여 탐색. 점주가 수동 블락했거나 앱으로 매칭 마감된 가게는 검색에서 자동 제외

  5. 5. 예약 공고 등록 및 예약금 결제

    원하는 매장에 예약 요청서를 발송하며, 노쇼 방지를 위한 소액의 디포짓(예약금) 결제 진행

  6. 6. 매칭 완료 및 비상 양도 활성화 킬러 기능

    점주가 수락하면 매칭 확정. 만약 행사 취소 등 비상 상황 발생 시 [예약 슬롯 양도] 기능을 통해 타 학과/동아리에 권한 인계 가능

3. 오프라인 예외 대처: 원터치 타임 블락 (One-Touch Time Block)

점주가 오프라인 영업(전화, 워크인, 단골 예약)으로 특정 날짜의 좌석이 확보되었을 때, 다른 학생들이 요청서를 보내거나 탐색하는 피로도를 줄이기 위한 점주 전용 스크린 작동 메커니즘입니다.
